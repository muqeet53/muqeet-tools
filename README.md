# muqeet-tools v0.3.0 - Ethical Network Auditor

Python library for learning network testing. Only for YOUR OWN network.

## Install
pip install requests rich
pip install -e .

## Run
python muqeet_audit_single.py
or
muqeet-audit

## Features
- Ping, DNS Lookup
- Website Status & Latency
- My IP Info
- Safe Port Scanner (only private IPs)

## Warning
For educational use only. Only scan 127.0.0.1 or 192.168.x.x
